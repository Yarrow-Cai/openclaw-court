## 三、三省六部对照（旧制 → 今制）

| 三省六部 | 今制 | 差异 |
|---|---|---|
| 中书省（起草诏令） | **丞相** | 中书只管写，丞相还要派差与汇总 |
| 门下省（封驳审议） | **御史大夫** | 门下是事前审议，御史是**事后核验**，且有签字权 |
| 尚书省（执行总署） | **差役派发**（丞相直派） | 撤掉尚书这一层，少一道手 |
| 六部（分曹执行） | **差役池**（外部 Agent） | 不设常设部门，按旨点人 |
| 皇帝 | 大王 | 同 |

**撤了什么**：尚书省、六部编制、门下的事前审议。
**加了什么**：御史的**签结权**——不签，事不算完。

一句话：旧制败在「无人签字」，今制胜在「一支笔」。

## 四、每次差遣的固定动作

1. 丞相出 `dispatch.json`（六字段，不许加）
2. 御史登记（记 `job.json` 与 `dispatch.json` 已齐）
3. 适配器执行 `adapters/<差役>.sh dispatch.json`
4. 产物落 `artifacts/<job-id>/`
5. 御史核验 → 签 `receipt.json`
6. 太子回奏

**任一步缺失，任务停在「在办」，不得口头宣称完成。**

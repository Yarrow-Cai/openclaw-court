# 制度对照：秦制 vs 三省六部

## 一、秦制原貌

秦王政称始皇帝后，中央官制为**三公九卿**。

### 三公

| 官职 | 职掌 | 史料要点 |
|---|---|---|
| **丞相** | 行政总揆，「天下之事皆决丞相府」 | 秦设左、右丞相，**以右为上** |
| **太尉** | 掌军政，最高军事长官 | **不常置**，有大战方任命，事毕改官 |
| **御史大夫** | 副丞相，掌图籍章奏、监察百官 | 「银印青绶，掌副丞相」；皇帝的耳目 |

三者**互不统属，直接对皇帝负责**。

### 九卿

奉常（宗庙礼仪）、郎中令（宫殿掖门）、卫尉（宫门屯卫）、太仆（车马）、
廷尉（刑狱）、典客（外交）、宗正（宗族）、治粟内史（财赋）、少府（山海池泽与手工业）。

### 地方

郡县两级，郡守、县令，垂直听命，不设分封。

## 二、三省六部（隋唐）

| 机关 | 职掌 |
|---|---|
| 中书省 | 起草诏令 |
| 门下省 | 封驳审议 |
| 尚书省 | 执行总署，下辖六部 |

**特点**：决策、审议、执行三权分立，制度设计精密。
**代价**：一道诏令要过四道手（中书草 → 门下审 → 尚书派 → 六部行），
每道手都是一次上下文转换，链条越长越容易在中间烂掉。

---

## 三、本设计取谁舍谁

| 取 | 理由 |
|---|---|
| 三公互不统属 | 执行与核验永不同人，杜绝自审自签 |
| 御史独立监察 | 把「回奏」从自觉变成制度：不签结不算完 |
| 太尉不常置 | 重型差役按需征召，平时不养（省 token、省上下文） |
| 郡县直达 | 丞相直派差役，撤掉尚书这一层 |

| 舍 | 理由 |
|---|---|
| 九卿常设编制 | 常设部门多一层翻译，外部 Agent 直接点用更短 |
| 门下事前审议 | 事前审议挡不住「办了没回音」，事后核验才管用 |
| 尚书省 | 纯转发层，无独立判断，撤 |

---

## 四、一句话总结

> **旧制败在无人签字，今制胜在一支笔。**

三省六部的角色名号保留作对照（中书→丞相、门下→御史、尚书→差役派发），
但制度骨架取秦制：**三个角色、两道关卡、一支签笔。**
